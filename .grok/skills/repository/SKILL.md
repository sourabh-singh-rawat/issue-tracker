# Repository

Persistence only. Canonical: `platform-service` `features/organizations/repositories`.

Feature slice wiring: `service-feature`. Domain rules / events: `service`. Naming: `AGENTS.md`.

## Layout

```text
services/<svc>/src/
  db/
    columns.ts          # idColumn + auditColumns
    tables/X.ts         # pgTable + relations + $inferSelect
    tables/index.ts
    schema.ts           # re-export tables (+ OutboxMessages when used)
    types.ts            # Database, Transaction, DbClient
  features/<feature>/repositories/
    IFooRepository.ts
    FooRepository.ts
    index.ts
```

## Table

Use `idColumn` + `auditColumns`. Export select/insert types from the table file. Re-export from `db/schema.ts` and `db/tables/index.ts`.

```ts
export const Organizations = pgTable(
  "organizations",
  {
    ...idColumn,
    tenantId: uuid("tenant_id").notNull().references(() => Tenants.id),
    name: varchar("name", { length: 255 }).notNull(),
    slug: varchar("slug", { length: 100 }).notNull(),
    ...auditColumns,
  },
  (table) => [unique().on(table.tenantId, table.slug)],
);

export type Organization = typeof Organizations.$inferSelect;
export type NewOrganization = typeof Organizations.$inferInsert;
```

**Do not** run `db:generate` / edit `drizzle/**` / migrate unless the user explicitly asks. Table TS only → tell the user the generate command (`AGENTS.md`).

## Interface + naming

Drop the entity noun. Persistence verbs — not domain `create` / `getById`.

| Method | Meaning |
| ------ | ------- |
| `save` | insert |
| `update` | patch; return row or `null` |
| `findById` / `findByIds` / `findMany` | read; **null / empty**, never throw not-found |
| `existsBy…` | boolean existence |
| `softDelete` / `hardDelete` | delete |

```ts
export type OrganizationRepositoryOptions = { tx: DbClient };

export interface IOrganizationRepository {
  save: (
    entity: CreateOrganizationEntity,
    options?: OrganizationRepositoryOptions,
  ) => Promise<Organization>;
  update: (
    id: string,
    entity: UpdateOrganizationEntity,
    options?: OrganizationRepositoryOptions,
  ) => Promise<Organization | null>;
  findById: (id: string) => Promise<Organization | null>;
  findByIds: (ids: string[]) => Promise<Organization[]>;
  findMany: (filter: ListOrganizationsFilter) => Promise<Organization[]>;
  existsBySlugInTenant: (tenantId: string, slug: string) => Promise<boolean>;
  softDelete: (id: string, options?: OrganizationRepositoryOptions) => Promise<boolean>;
}
```

Qualify filters (`existsBySlugInTenant`), not the type name (`findOrganizationById`).

## Implementation

- `@injectable()` class; inject `TYPES.Database`
- `private client(options?) { return options?.tx ?? this.db; }` for writes that participate in a service transaction
- `uuidv7()` for new ids; bump `version` on update/softDelete
- Filter soft-deleted rows with `isNull(table.deletedAt)` unless the method is explicitly about deleted rows
- No authz, no events, no `ApplicationError` not-found — that belongs in `service`

```ts
@injectable()
export class OrganizationRepository implements IOrganizationRepository {
  constructor(@inject(TYPES.Database) private readonly db: Database) {}

  async save(
    entity: CreateOrganizationEntity,
    options?: OrganizationRepositoryOptions,
  ): Promise<Organization> {
    const client = this.client(options);
    const [created] = await client
      .insert(Organizations)
      .values({
        id: uuidv7(),
        tenantId: entity.tenantId,
        name: entity.name,
        slug: entity.slug,
        createdAt: new Date(),
        version: 1,
      })
      .returning();
    return created;
  }

  private client(options?: OrganizationRepositoryOptions) {
    return options?.tx ?? this.db;
  }
}
```
